# data/ — 자동판독·자동생성 지식베이스

e-safety 플랫폼이 사진 한 장에서 위험 판독 → 위험성평가표 → 작업허가서를 연쇄 생성할 때 쓰는 자료이다.
프런트엔드(`index.html`)에는 같은 내용이 임베드되어 있고, `api/read.js`는 `indicators.json`을
Claude 비전 모델의 시스템 프롬프트에 넣는다.

| 파일 | 내용 |
|---|---|
| `kb.json` | 통합 지식베이스 전체 — 표지 39종(전기 U01~U19 · 일반 G01~G20)의 5개 언어 문구, 위험성평가 행, PTW·P-94 매핑, 보정규칙, 키워드, 기본 사례, 허가서 양식 문자열 2종 |
| `indicators.json` | 판독용 요약 — 표지별 영역(dom)·명칭·군·판독 단서·원인·근거 조문·CSI 통계·감소대책·빈도/강도·허가 매핑 (한국어/영어) |
| `keywords.json` | 키워드 판독 사전(표지 39종 × 한/영 키워드)과 무매칭 시 기본 표지(전기 3종·일반 3종) |
| `ptw_rules.json` | 허가서 양식 문자열 2종 — `ptw`: C-C-49-2026 사전작업허가서(전기), `p94`: KOSHA GUIDE P-94-2021 <별지 양식2> 일반위험작업 허가서 — 와 표지→허가 항목 매핑 |
| `correction_rules.json` | 가능성 보정규칙 4종(계절·강우·시간대·언어장벽) |
| `sample_case.json` | 기본 제공 사례(옥외 주상 변압기 물청소 감전)의 판독 결과 5건과 마커 좌표 |
| `groups.json` | 표지 군(전기 9군·일반 8군)의 순서와 5개 언어 명칭, 영역 명칭 |

## 영역(dom)과 허가서 양식

| 영역 | 표지 | 시트 3 양식 | 근거 |
|---|---|---|---|
| `elec` 전기설비부문 | U01~U19 | 사전작업허가서(PTW) | KOSHA GUIDE C-C-49-2026 안전작업허가에 관한 기술지원규정 |
| `gen` 일반작업(비전기) | G01~G20 | 일반위험작업 허가서 (화기 표지 시 화기작업 허가서) | KOSHA GUIDE P-94-2021 안전작업허가지침 <별지 양식1·2> |

일반 표지의 CSI 통계는 건설공사 안전관리 종합정보망(CSI) 사고 30,896건(2021.01~2026.08)을 집계한 값이다.
