# data/ — 자동판독·자동생성 지식베이스

e-safety 플랫폼이 사진 한 장에서 위험 판독 → 위험성평가표 → 사전작업허가서(PTW)를
연쇄 생성할 때 쓰는 자료이다. 프런트엔드(`index.html`)에는 같은 내용이 임베드되어 있고,
`api/read.js`는 `indicators.json`을 Claude 비전 모델의 시스템 프롬프트에 넣는다.

| 파일 | 내용 | 출처 단계 |
|---|---|---|
| `kb.json` | 통합 지식베이스 전체 — 표지 19종(U01~U19)의 5개 언어 문구, 위험성평가 행(작업내용·분류·원인·유해위험요인·관련근거·현재상태·감소대책·빈도·강도), PTW 매핑, 보정규칙, 키워드, 기본 사례, PTW 양식 문자열 | 3·4·5·9단계 |
| `indicators.json` | 판독용 요약 — 표지별 명칭·군·판독 단서·원인·근거 조문·CSI 통계·감소대책·빈도/강도·PTW 매핑 (한국어/영어) | 3·5단계 |
| `keywords.json` | 키워드 판독 사전(표지 19종 × 한/영 키워드 145개)과 무매칭 시 기본 표지 3종 | 9단계 |
| `ptw_rules.json` | PTW 양식 문자열(안전조치 14항목·점검 14항목·보충허가 6종·정전작업 6단계)과 표지→허가 항목 매핑 | 4·5단계 |
| `correction_rules.json` | 가능성 보정규칙 4종(계절·강우·시간대·언어장벽) | 3단계 |
| `sample_case.json` | 기본 제공 사례(옥외 주상 변압기 물청소 감전)의 판독 결과 5건과 마커 좌표 | 9단계 |
| `groups.json` | 표지 군 9종의 순서와 5개 언어 명칭 | 9단계 |
