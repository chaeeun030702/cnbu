# 전기안전 다국어 안전문서 자동생성 플랫폼

충북대학교 안전공학과 이채은 · 지도교수 원정훈
「Database 기반 생성형 AI 활용 전기안전 다국어 위험성평가표, 사전작업허가서 자동 웹생성 연구」 4단계 산출물

현장사진 한 장을 올리면 다음 네 가지 문서를 만든다. 한국어를 기준으로 하고 영어·중국어·베트남어·우즈베크어 가운데 하나를 함께 적는다.

1. 현장사진 위험분석과 분석 근거(RAG) — A4 가로
2. 위험성평가표 — 3×3 위험성 추정기준은 평가표 맨 아래에 둔다
3. 사전작업허가서(PTW) — A4 세로
   - 전기 표지(U01~U19)가 하나라도 있으면 KOSHA GUIDE C-C-49-2026 「안전작업허가에 관한 기술지원규정」 양식을 쓴다.
   - 일반 표지(G01~G20)만 있으면 일반 건설 사전작업허가서를 쓴다. 두 양식 모두 KOSHA GUIDE C-C-49-2026 「안전작업허가에 관한 기술지원규정」(2026. 1. 30. 개정)을 근거로 한다.
4. 다국어 안전포스터 — A3 세로, 외국어가 위·한국어가 아래. ChatGPT 실사 이미지를 넣을 수 있다.

자동 생성 결과는 초안이다. AI는 최초 검토, 최종 판단은 관리감독자가 진행.

## 위험 분석 자료 발송 (메일 · 문자)

상단 바의 **✉️ 메일 발송** · **💬 문자 발송** 버튼을 누르면 **받는 이메일 주소 / 휴대폰 번호를 입력하는 창**이 뜨고, 현장사진 위험성평가 결과를 그 주소·번호로 보낸다(허가서·포스터는 보내지 않음). 마지막에 입력한 값은 이 브라우저에 기억한다. 서버리스 함수 `api/notify.js`가 발송한다.

- 제목(메일·문자 공통): `[경고] 현장사진 위험성 분석(위험 N건 · 9이상 M건)` — 9이상은 위험성(빈도×강도, 최대 9)이 9 이상인 건수.
- 메일: 본문 맨 위 사이트 링크 + 위 제목 + **분석 결과 화면 PDF**(A4 가로, 위험분석·위험성평가표 전 쪽 — 브라우저에서 html2canvas·jsPDF로 만듦) + **현장사진 위험 분석 sheet**(HTML, 화면의 ‘저장’과 같은 파일) 첨부. 보내는 방법은 ① 서버 환경변수(`NOTIFY_TOKEN`+[Resend](https://resend.com)) ② **왼쪽 ⑩ 발송 설정에 저장한 Gmail 계정(앱 비밀번호)** — 토큰·서버 설정 없이 그 계정으로 SMTP 발송 ③ 아티팩트의 Gmail 커넥터. 서버가 아무 Gmail 계정이나 시도하지 못하도록 ②는 허용 목록 계정만 된다(기본: 기본 사용자 2명의 Gmail, 환경변수 `NOTIFY_GMAIL_USERS`로 변경).
- 문자: 위 제목 + 줄바꿈 + `https://e-safety.vercel.app/` (2줄) — [Solapi](https://solapi.com). 왼쪽 **⑩ 발송 설정**에 Solapi **API Key · API Secret · 등록한 발신번호**를 저장해 두면(이 브라우저에만) **💬 문자 발송**에서 받는 사람만 고르면 된다. 키가 없으면 ⑩으로 안내한다. 서버 환경변수와 발송 토큰이 필요 없다. 키는 발송 요청에만 실어 서버를 거쳐 Solapi로 전달하며 서버는 저장하지 않는다. Solapi가 일부 발송을 거절하면(미등록 발신번호 등) 사유를 화면에 보여 준다. 한글 기준 90바이트를 넘으면 자동으로 LMS. 긴 대시(—)는 문자에서만 모양이 같은 ―(U+2015)로 바꿔 보낸다(EUC-KR 범위).
- 받는 사람: 입력창의 **체크리스트**(👤 사용자 등록에 등록한 사용자 — 기본 2명은 `assets/recipients.js`의 `PRESETS`를 순서대로 짝지은 것) + **추가 입력 1칸**(비워 둠). 체크한 항목과 추가 입력을 합쳐 최대 10명. 마지막 체크 상태는 이 브라우저에 기억하고 처음엔 첫 항목만 체크된다. 이메일은 주소, 문자는 국내 휴대폰 번호(010 등) 형식이 아니면 보내지 않는다. **저장소·사이트가 공개이면 `recipients.js` 값도 공개된다.** 입력이 비어 서버에 도달하면 환경변수 `NOTIFY_EMAIL_TO` / `NOTIFY_SMS_TO`(선택)를 기본값으로 쓴다.
- 남용 방지: 발송 토큰(`NOTIFY_TOKEN`)이 맞아야 보낼 수 있다(입력창에서 한 번 넣으면 이 브라우저에만 저장, 틀리면 폐기). 같은 채널의 연속 발송은 20초 간격으로 제한한다. **토큰이 유출되면 누구에게나 보낼 수 있으므로** 토큰은 혼자만 안다.

### 입력란 켜기/끄기

헤더 맨 왼쪽의 **패널 아이콘**(◧)으로 왼쪽 입력란(① ~ ⑩)을 접고 편다. 접으면 오른쪽 문서가 화면 너비에 다시 맞춰져 넓게 보이고, 상태는 이 브라우저에 기억한다(다시 열어도 유지).

### 위험 요인이 없을 때

AI 판독이 사진에서 위험 요인을 하나도 찾지 못하면(또는 키워드 판독에서 맞는 단어가 없으면) 임의의 표지를 채우지 않고, 현장사진 위험 분석 1면·위험성평가표에 **‘위험 요인 확인되지 않음, 관리감독자 확인 요함’**(5개 언어 병기)을 보인다. 예전에는 AI가 ‘없음’이라고 판독해도 실패로 보고 키워드 판독으로 대체해, 키워드가 없으면 기본 표지 3종(U01·U05·U16)을 그대로 적용했다. 이 경우 감시 모드는 알림을 보내지 않고 `위험 요인 확인되지 않음` 상태만 표시한다. 또한 **2. 사전작업허가서(PTW)와 3. 다국어 안전포스터 시트는 만들지도 보이지도 않는다**(표지가 없으면 허가서·포스터의 근거가 없기 때문). 다음 판독에서 위험 요인이 나오면 그때 새로 만든다.
같은 규칙이 **지식베이스 표지가 하나도 없는 경우**(AI가 표지는 못 찾고 ‘지식베이스 밖 추가 위험’만 낸 경우, 또는 직접 추가한 항목뿐인 경우)에도 적용된다. 허가서·포스터는 지식베이스 표지의 법령·대책·통계로 만들기 때문에, 표지 없이 만들면 포스터가 처음 화면의 표본(물속 펌프 감전) 문구를 그대로 남겨 사진·AI 판독과 어긋났다. 이 경우 상태창에 `지식베이스 표지가 없어 사전작업허가서·안전포스터는 만들지 않습니다`라고 안내하고, 추가 위험은 위험분석·평가표에만 반영한다. AI 호출 자체가 실패한 경우(키 없음·시간 초과 등)는 키워드 판독으로 대체하되 같은 규칙을 따른다.

### 저장 — Excel(.xlsx)

상단 **💾 저장 ▾ → 위험성평가표 Excel (.xlsx · A4 가로)**: 화면의 위험성평가표(순번·작업내용·분류·원인/유해요인·상세·법적 근거·현재상태·빈도·강도·위험·감소대책·개선일·완료일·담당자)와 현장 정보(현장명·평가일·사진·공종·평가팀·가능성 보정·평가 근거)를 한 시트로 저장한다. 편집 모드에서 고친 값과 선택한 병기 언어 번역도 그대로 들어간다. 위험 칸은 위험성 숫자에 등급 색(9 적색·6~8 주황·3~5 황색·1~2 녹색)과 `9 (높음)` 표시를 붙인다.
- **인쇄 설정**: A4 가로, 여백 **위 2.0cm · 왼쪽 1.5cm · 오른쪽 1.0cm · 아래 1.0cm**, 폭을 1쪽에 맞춤(`fitToWidth`), 가운데 맞춤, 표 머리글 2줄 반복, 아래 가운데 `쪽 / 전체` 번호.
- 파일명 `위험성평가표_<현장명>_<날짜>.xlsx`. Excel 라이브러리(`assets/vendor/exceljs.min.js`, ExcelJS 4.4.0, 약 0.9MB)는 처음 저장할 때만 내려받는다. 아티팩트에서는 저장 메뉴가 숨겨져 있다.

### 결과 문서 확대·축소

오른쪽 **결과 문서(현장사진 위험 분석·평가표 등)만** 확대·축소한다 — 왼쪽 입력란은 그대로다. **Ctrl(⌘) + 마우스 휠**, 트랙패드 **핀치**, 터치 화면의 **두 손가락 핀치**로 25~150% 사이에서 바꾸고(누른 지점을 기준으로 확대), 확대하면 오른쪽 영역이 스크롤되어 밀어서 볼 수 있다. 빈 배경을 두 번 누르면 화면 너비에 맞춘다(`맞춤`). 그냥 휠은 지금처럼 문서를 위아래로 스크롤한다. 배율은 잠깐 오른쪽 아래에 표시된다.
기존 `zoom` 방식은 iPad Safari에서 iframe 안쪽까지 줄지 않아 위험 분석 오른쪽 열이 잘렸으므로 `transform: scale`로 바꾸고 문서 영역 크기를 배율에 맞췄다.

### 상단 메뉴 (iPad 최적화)

화면 폭이 1500px 이하(iPad 가로 1180px·1024px, 세로)이면 상단 메뉴는 **아이콘만** 보이고(글자는 길게 누르면 뜨는 설명), 촬영 중에는 상태 글자(`촬영 중 · 1분 · N장`)만 남는다. 터치 기기에서는 버튼을 42px 높이로 키운다. 넓은 화면은 아이콘+글자.

### 감시 모드

상단 바 **📷 감시 모드**: 간격은 **1분**. 시작하면 **3초 뒤 첫 사진**을 찍어 '① 현장사진 올리기'에 반영하고, 공유 시트(**공유 / 사진에 저장** → iPad '이미지 저장')로 보낸다. 공유 시트는 화면을 누른 직후에만 열릴 수 있어 자동으로 안 열리면 **📥 첫 사진 공유 / 사진에 저장** 버튼이 뜨고, 그 버튼을 누르면 열린다. 이후 사진은 촬영 페이지와 같은 저장소(IndexedDB)에 쌓인다.

### 사용자 등록 · 감시 모드 위험 알림

- 상단 바 녹색 **👤 사용자 등록**(감시 모드 왼쪽): **기본 사용자 2명**(이메일·문자 번호) + **추가 사용자**(이름·이메일·휴대폰, 최대 20명)를 등록한다. 추가·삭제는 이 브라우저(localStorage)에만 저장된다. 사용자마다 **알림** 체크로 자동 알림 수신 여부를 정한다.
- **위험 알림 루틴**(같은 창에서 켠다, 기본 꺼짐): 감시 모드 중 찍은 사진을 AI(②를 AI 판독으로)로 분석하고, 위험성(빈도×강도)이 선택한 단계 이상인 표지가 하나라도 나오면(단계 3종: **3 이상**(중간 이상) · **6 이상**(높음 이상, 기본) · **9 이상**(최고) — 사용자 등록 창에서 고른다) 알림 사용자 전원에게 **메일**(제목·본문은 위와 같고 "감시 모드 자동 알림" 문구, 분석 결과 PDF + sheet 첨부, ⑩의 Gmail 계정 필요)과 **문자**(제목 + 주소 2줄, ⑩의 Solapi 키 필요)를 함께 보낸다. 저장된 설정이 있는 쪽만 보내고, 하나라도 나가면 쿨다운이 시작된다. 분석이 끝나기 전에 찍은 사진은 건너뛰고, 한 번 보낸 뒤 10분은 다시 보내지 않으며 실패하면 1분 뒤 다시 시도한다. 키워드 대체 판독은 사진을 보지 않으므로 알림 근거로 쓰지 않는다.
- 자동 알림은 사람이 누르지 않아 Gmail 커넥터를 쓸 수 없다. 왼쪽 **⑩ 발송 설정**에 **Gmail 주소 + 앱 비밀번호**(Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호)를 저장해야 한다(이 브라우저에만 저장, 발송 요청에만 실리고 서버는 저장하지 않음). 감시 모드·루틴은 아티팩트에서 동작하지 않는다(카메라 차단).

Vercel 환경변수(Settings → Environment Variables):

| 변수 | 설명 |
|---|---|
| `NOTIFY_TOKEN` | 발송 토큰 (필수) |
| `RESEND_API_KEY` | 이메일 키. `NOTIFY_EMAIL_FROM`은 선택(기본 `onboarding@resend.dev` — 도메인 인증 전에는 Resend 가입 주소로만 발송 가능). `NOTIFY_EMAIL_TO`는 선택(입력이 없을 때의 기본 받는 주소) |
| `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER` | (선택) 문자를 입력창 대신 서버 키로 보낼 때만. 보통은 입력창에 직접 넣으므로 필요 없다. `NOTIFY_SMS_TO`는 입력이 없을 때의 기본 받는 번호 |

설정이 없는 채널은 ‘서버 미설정’으로 알려 준다. 값은 저장소에 적지 않는다. 첨부 sheet가 약 3MB를 넘으면 보낼 수 없다(Vercel 요청 크기 제한).

## Claude 아티팩트 버전 (Gmail 커넥터 메일 발송)

claude.ai 아티팩트로도 같은 화면을 게시할 수 있다. 아티팩트에서는 `window.claude.use('mcp')`가 열리고, `assets/app.js`가 이를 감지해 **Gmail 커넥터 모드**로 바뀐다(`connInit`). Vercel 사이트에서는 이 코드가 동작하지 않고 기존 방식 그대로다.

- 메일: **✉️ 메일 발송** → 받는 주소 입력창 → 내 Gmail 계정(Gmail 커넥터 `send_message`)으로 직접 발송. **발송 토큰·서버 설정이 필요 없다.** 본문 맨 위에 사이트 링크(`https://e-safety.vercel.app/`), 제목은 `[경고] 현장사진 위험성 분석(위험 N건 · 9이상 M건)`, 현장사진 위험 분석 sheet(HTML) 첨부. (Gmail 커넥터는 본문의 `<img>`를 모두 지워 JPG를 본문에 넣을 수 없고, HTML 첨부가 용량·화질 면에서 JPG 여러 장보다 낫다.) 커넥터 입력 한도(1MiB)를 넘는 첨부는 파일 인자(`$file`)로 보내고, 그 경로가 안 되면 gzip(`.html.gz`)으로 줄여 보낸다.
- Vercel 사이트의 ⑩ 발송 설정에는 **서버에 메일 설정(`NOTIFY_TOKEN`·Resend)이 있을 때만** 발송 토큰 칸이 보인다. 없으면 숨기고, ✉️ 메일 발송은 아티팩트 버전(Gmail 커넥터)에서 보내라고 안내한다. 아티팩트 안에서는 연결을 기다리지 않고 처음부터 토큰·문자 키 칸을 숨긴다.
- 아티팩트에서 쓸 수 없는 기능은 숨긴다: 문자 발송(서버·Solapi 필요), 저장·인쇄(다운로드·인쇄 차단), 감시 모드(카메라 차단). AI 사진 판독(서버리스 함수)도 없어 키워드 판독만 된다.
- 로그인한 본인 계정으로만 동작하며, 커넥터 권한을 쓰는 아티팩트는 공개 링크로 공유할 수 없다.
- 게시 파일 만들기: `python3 build/artifact.py OUT_DIR` — index.html 을 아티팩트 규격(태그 없는 본문, CSS·JS 합침)으로 바꾸고 나머지 페이지·이미지를 복사한다. `OUT_DIR/index.html` 을 `file_path`로, 나머지를 `files`로, `capabilities: {mcp: {servers: [{server: "Gmail", tools: ["send_message"]}]}}` 와 함께 게시한다.
