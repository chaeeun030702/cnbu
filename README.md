# 전기안전 다국어 안전문서 자동생성 플랫폼

충북대학교 안전공학과 이채은 · 지도교수 원정훈
「Database 기반 생성형 AI 활용 전기안전 다국어 위험성평가표, 사전작업허가서 자동 웹생성 연구」 4단계 산출물

현장사진 한 장을 올리면 다음 네 가지 문서를 만든다. 한국어를 기준으로 하고 영어·중국어·베트남어·우즈베크어 가운데 하나를 함께 적는다.

1. 현장사진 위험분석과 분석 근거(RAG) — A4 가로
2. 위험성평가표 — 3×3 위험성 추정기준은 평가표 맨 아래에 둔다
3. 사전작업허가서(PTW) — A4 세로
   - 전기 표지(U01~U19)가 하나라도 있으면 KOSHA GUIDE C-C-49-2026 「안전작업허가에 관한 기술지원규정」 양식을 쓴다.
   - 일반 표지(G01~G20)만 있으면 일반 건설 사전작업허가서를 쓴다. 두 양식 모두 KOSHA GUIDE C-C-49-2026 「안전작업허가에 관한 기술지원규정」(2026. 1. 30. 개정)을 근거로 한다.
4. 다국어 안전포스터 — A3 세로, 외국어가 위·한국어가 아래. ChatGPT 실사 이미지를 넣을 수 있다.

자동 생성 결과는 초안이다. AI는 최초 검토, 최종 판단은 관리감독자가 진행.

## 배포

Vercel 프로젝트 `cbnu-safety`. 빌드 단계 없이 정적 파일과 서버리스 함수 1개로 동작한다.
AI 판독을 서버에서 쓰려면 Vercel 환경변수 `ANTHROPIC_API_KEY`를 넣는다. 없으면 화면 ⑧에 키를 넣거나 키워드 판독을 쓴다.

## 위험 분석 자료 발송 (메일 · 문자)

상단 바의 **✉️ 메일 발송** · **💬 문자 발송** 버튼을 누르면 **받는 이메일 주소 / 휴대폰 번호를 입력하는 창**이 뜨고, 현장사진 위험성평가 결과를 그 주소·번호로 보낸다(허가서·포스터는 보내지 않음). 마지막에 입력한 값은 이 브라우저에 기억한다. 서버리스 함수 `api/notify.js`가 발송한다.

- 제목(메일·문자 공통): `[경고] 현장사진 위험성평가표 — 현장명 (위험 N건 · 높음 M)` — 현장명이 비어 있으면 ` — 현장명`은 뺀다. 높음은 위험성 6 이상.
- 메일: 위 제목 + **현장사진 위험 분석 sheet**(위험분석·위험성평가표 HTML, 화면의 ‘저장’과 같은 파일) 첨부 — **Gmail**(SMTP, 앱 비밀번호). `nodemailer`로 보낸다(`package.json`).
- 문자: 위 제목 — [Solapi](https://solapi.com). 한글 기준 90바이트를 넘으면 자동으로 LMS. 긴 대시(—)는 문자에서만 모양이 같은 ―(U+2015)로 바꿔 보낸다(EUC-KR 범위).
- 받는 사람: 이메일은 주소, 문자는 국내 휴대폰 번호(010 등)를 **최대 3개**까지(쉼표로 구분) 입력한다. 형식이 맞지 않으면 보내지 않는다. 입력이 비어 서버에 도달하면 환경변수 `NOTIFY_EMAIL_TO` / `NOTIFY_SMS_TO`(선택)를 기본값으로 쓴다.
- 남용 방지: 발송 토큰(`NOTIFY_TOKEN`)이 맞아야 보낼 수 있다(입력창에서 한 번 넣으면 이 브라우저에만 저장, 틀리면 폐기). 같은 채널의 연속 발송은 20초 간격으로 제한한다. **토큰이 유출되면 누구에게나 보낼 수 있으므로** 토큰은 혼자만 안다.

Vercel 환경변수(Settings → Environment Variables):

| 변수 | 설명 |
|---|---|
| `NOTIFY_TOKEN` | 발송 토큰 (필수) |
| `GMAIL_USER`, `GMAIL_APP_PASSWORD` | 메일을 보낼 Gmail 주소와 **앱 비밀번호**(16자리, 공백이 있어도 됨). 일반 로그인 비밀번호는 쓸 수 없다. `NOTIFY_EMAIL_TO`는 선택(입력이 없을 때의 기본 받는 주소) |
| `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER` | 문자 키·시크릿, **사전 등록한 발신번호**. `NOTIFY_SMS_TO`는 선택(입력이 없을 때의 기본 받는 번호) |

설정이 없는 채널은 ‘서버 미설정’으로 알려 준다.

Gmail 앱 비밀번호 만들기: Google 계정 → 보안 → **2단계 인증** 켜기 → [앱 비밀번호](https://myaccount.google.com/apppasswords) → 이름(예: e-safety) 입력 → 생성된 16자리를 `GMAIL_APP_PASSWORD`에 넣는다. 보내는 주소는 항상 `GMAIL_USER`이며, 받는 사람 주소는 입력창에서 정한다. Gmail 발송 한도(일반 계정 하루 약 500통)가 적용된다. 값은 저장소에 적지 않는다. 첨부 sheet가 약 3MB를 넘으면 보낼 수 없다(Vercel 요청 크기 제한).

## 개인정보

사업장명·성명 같은 식별정보는 받지 않는다. 키워드 판독과 직접 선택은 사진을 브라우저 안에서만 쓴다.
AI 판독을 고르면 축소한 사진이 서버리스 함수를 거쳐 Anthropic API로 보내져 판독에만 쓰이며 저장하지 않는다.
